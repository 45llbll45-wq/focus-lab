# Focus Lab (مختبر التركيز وصناعة المحتوى) 🚀

تطبيق ويب شخصي موجّه للهاتف (Mobile-First) مصمم خصيصاً لمساعدتك أثناء تعلم وتطبيق **AI Automation**، وتوثيق رحلتك اليومية وتحويل ما تتعلمه مباشرة إلى أفكار محتوى ومسودات جاهزة للنشر.

---

## ✨ المميزات الرئيسية

1. **الرئيسية (وش بننجز اليوم؟)**: متابعة الزخم اليومي، إدارة المهام، والبدء الفوري.
2. **إضافة مهمة (وش تبين تنجزين؟)**: تحديد المهمة، التصنيف، الوقت، ومستوى الطاقة.
3. **الخطة الذكية (كيف بنسويه؟)**: تقسيم ذكي مع دعم خاص لمستوى الطاقة المنخفضة (Micro-step < 5 دقائق).
4. **جلسة التركيز (وش الخطوة الحالية؟)**: مؤقت دائري هادئ بدون تشتيت وتنبيهات صوتية.
5. **تدوين التعلم (وش تعلمت؟)**: تدوين حر وأسئلة توجيهية لاستخراج الفائدة والتحدي والتجربة والنتيجة.
6. **توليد المحتوى (وش أقدر أنشر؟)**: تحويل التجربة إلى 4 قوالب محتوى (Reel، Carousel، Post، Tutorial) مع خطاف (Hook) جاهز.
7. **شاشة الإنجاز (خلصنا! 🎉)**: احتفال Confetti وملخص متكامل للجلسة.
8. **مكتبة المحتوى**: تخزين دائم للأفكار، إدارة الحالات، وتصدير كامل المحتوى كملف Markdown بنقرة واحدة.

---

## 🛠️ التقنيات المستخدمة

- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4**
- **Lucide React Icons**
- **Canvas Confetti & Web Audio API**
- **IBM Plex Sans Arabic Typography (RTL)**
